Features

Offline profiles

Multiple saved usernames with correct offline UUIDs. No Mojang or Microsoft login.

Every loader

Vanilla, Fabric, Quilt, Forge (incl. legacy ≤1.12), NeoForge — headless installs.

Mods

Modrinth browser with version filtering, .mrpack import, per-instance mod lists.

Skins everywhere

Auto-generated skin resource pack works even on vanilla; capes on modded via CustomSkinLoader.

Auto Java

Finds installed JDKs, downloads Temurin 8/17/21 when missing. Java 8 enforced for old versions.

Fast & isolated

Parallel downloads with live progress, natives extraction, one folder per instance.
